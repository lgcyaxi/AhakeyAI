# Third-party notices for the Windows local-model build

The Windows build includes the sherpa-onnx engine. Model weights are optional:
download them explicitly in Settings or build with `-IncludeLocalModel`.

- Project: https://github.com/k2-fsa/sherpa-onnx
- Version: 1.13.7
- Components: JVM API and Windows x64 native runtime
- License: Apache License 2.0

`licenses/sherpa-onnx-Apache-2.0.txt`.
